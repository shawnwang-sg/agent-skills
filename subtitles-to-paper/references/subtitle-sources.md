# 字幕来源与输入检查

## 已有文件

优先使用用户给定的 SRT、VTT、TXT、已整理正文及映射。记录文件名、SHA-256、来源 URL（若已知）、字幕语言、人工/自动字幕性质及获取日期。文件没有时间戳时保留行号或段落位置，不能臆造时间轴。

SRT/VTT 要检查可解析性、空条目、起止时间、重复和重叠、语言、首尾及异常长空隙。VTT 的滚动字幕可能重复上一行，应根据时间与重复文本去重，不能将真正重复发言一并删除。HTML 错误页不算下载成功。

缺字幕不等于缺访谈：先区分无语音、音乐、漏识别、不同版本剪辑。只有字幕时可核对文本范围，不能声称已验证完整音轨覆盖。

## 仅提供网址

1. 确认嘉宾、主持人、节目期号、标题和日期；能取得时再核对时长。先查官方字幕、公开转录页或播放器字幕列表。
2. 优先按下节用 yt-dlp 列出字幕轨道，再下载目标语言。先取发布方提供的原语字幕；缺少时再取原语自动识别字幕，不盲取所有语言。
3. 发布方字幕、自动识别字幕、自动翻译字幕、不同语言或不同来源分别保存，文件名或子目录区分来源，防止同名覆盖。一般不为论文排版下载完整视频。
4. 官方转录页可作为文本来源，保留其章节、原链接、发布日期及原始文本。转录文本没有准确时轴时，不伪造逐条 SRT。
5. 当前工具获取失败时记录实际报错与完成边界。有登录或访问限制时走正常访问流程；不能把某个链接的失败推广成全站永久不可用。

若需替代链接，应核实是同一次对话：人物、节目、主题、起止内容及长度是否一致。其他同人物访谈、片段或重新剪辑版不能直接当作完整替代。保留原始链接和核对依据。

## 用 yt-dlp 下载字幕

用户所说的 “ytb-dl” 或 “yt-dl” 先对应到实际安装的工具。本节命令针对 **yt-dlp**；通过实际可执行文件的 `--version` 和 `--help` 核对，不把 youtube-dl 或其他同名程序当作完全兼容。优先复用工作区已有工具，再检查 PATH；不把某台电脑的绝对路径写成通用配置。

下面是命令模板，执行前把 `URL` 换成当前单个视频链接，`LANG_CODE` 换成列表中的完整语言代码，`NEW_SOURCE_DIR` 换成当前篇目独立版本的来源目录。Windows PowerShell 中，若使用带引号的完整 exe 路径，以 `& '实际路径/yt-dlp.exe'` 替换命令开头的 `yt-dlp`。

### 1. 列出字幕，不下载媒体

```text
yt-dlp --ignore-config --no-playlist --skip-download --list-subs -- "URL"
```

核对视频 ID、标题和目标访谈。传单个视频 URL；`--no-playlist` 不能把纯播放列表链接自动变成指定的一篇。`--ignore-config` 使旧的全局下载配置不混入本次命令；需要的网络参数在本次调用中明确提供。

区分字幕列表中的发布方字幕与自动字幕。英语轨道可能为 `en`、`en-US` 或带后缀的代码，中文也可能分简繁；按实际列表选择，不固定使用 `en` 或 `zh`。`--sub-langs` 支持正则，特殊字符应按字面转义；只选所需轨道，不默认用 `all` 或 `en.*`。

### 2. 下载发布方字幕

```text
yt-dlp --ignore-config --no-playlist --skip-download --write-subs --no-write-auto-subs --sub-langs "LANG_CODE" --sub-format "vtt/best" --no-overwrites -P "NEW_SOURCE_DIR/publisher" -o "%(id)s.%(ext)s" -- "URL"
```

`--write-subs` 表示站点提供的非自动字幕轨道，不足以证明其经过人工校对。文件保留原下载格式和语言后缀。优先 VTT 以保留源时间信息；若轨道只提供其他格式，按实际格式解析，不强行改扩展名。

### 3. 缺少原语字幕时下载自动字幕

```text
yt-dlp --ignore-config --no-playlist --skip-download --no-write-subs --write-auto-subs --sub-langs "LANG_CODE" --sub-format "vtt/best" --no-overwrites -P "NEW_SOURCE_DIR/automatic" -o "%(id)s.%(ext)s" -- "URL"
```

优先原始口语语言的识别轨道。英文访谈通常取英文来源后单独翻译中文；已有平台中文翻译可作为对照，但应另存于 `machine-translation` 目录并明确标记，不能冒充原语识别或独立校译。中文访谈仅处理中文。

不要在同一输出位置同时启用两种字幕下载：相同语言可能被优先级选择或同名文件掩盖。如确需两种，分别运行并使用不同来源目录。

### 4. 下载验收与后续处理

- 退出码为零仍可能没有目标字幕。必须核实实际字幕文件存在、非空、可解析，并检查语言、首尾 cue、异常空隙与时间顺序；不能把网页或报错文本当成字幕。
- 保存简短获取记录：原始 URL、视频 ID、标题、频道、可确认的日期与时长、获取时间、工具版本、字幕代码与类型、文件名、SHA-256、执行结果。未确认的元数据留空，不把上传日期当作访谈日期。
- VTT 可以直接进入整理流程。需要 SRT 时，从原件副本转换到独立目录，再核对 cue 和时间轴；不在唯一原件上直接加转换步骤。
- 没有字幕、无匹配语言、链接不受支持、HTTP 403/429、登录限制应分别记录。短暂网络故障可有限重试；无变化时保留错误并转入既有的恢复流程，不循环重试或自动下载整段视频、启动识别模型。
- cookies、账号令牌和带敏感参数的字幕临时 URL 不进入技能包、Git 或普通日志。仅保存可公开引用的原视频链接。

参数依据：[yt-dlp 官方字幕选项](https://github.com/yt-dlp/yt-dlp#subtitle-options)。以执行时本机版本的帮助为准。

## 已有媒体或分段字幕

只有核对疑点确有必要、且媒体已提供或下载在用户范围内时，才处理音轨。用 ffprobe 检查媒体实际时长和音轨；不要仅看扩展名和文件大小。

多段字幕合并须记录每段真实起点偏移，换算为完整时间轴，检查段间重复、遗漏与尾段。不要按“一段必定一小时”或文件名猜偏移。字幕前后有静音时，其首末 cue 不必恰好等于媒体边界。

CSV 使用标准 csv 解析；若面向中文 Excel 可用 UTF-8 BOM。来源测试结果加验证日期，旧测试仅作为线索。
