# paper-explain · 选中即学

读论文卡在一句话或一个词上时，用几行大白话把它讲懂。重点是技术上怎么理解、前因后果和关键；翻译和句型只是顺带，各一行。

提示词放在 `prompts/`，是唯一的来源：对话里用、潜研堂的「学习」按钮用，都是这两份。改了提示词就把 `prompts/version.txt` 里的数字加一，程序靠它区分新旧存档。

## 两种模式

| 模式 | 什么时候 | 提示词 | 输出 |
|---|---|---|---|
| 句 | 选中的是一句或几句（四个词以上） | `prompts/sentence.txt` | 七行：大意、前因、理解、后果、关键、翻译、句型 |
| 词 | 选中的是一个词或术语（三个词以内） | `prompts/word.txt` | 五行：是什么、为什么、在这里、翻译、搭配 |

## 输入

给模型的内容固定四行，别的不带：

```
论文：<标题>
小节：<小节名>
上下文：<选中所在的那一段，最多约 900 个字符，以选中为中心截取>
选中：<选中的文字>
```

讲懂一句话只需要它周围那一段。带全文既费 token，又会让讲解跑题。

## 讲的规矩

- **先讲技术，再讲语言。** 读者卡住多半是因为不知道这句在解决什么问题，所以「前因」和「理解」是主体，翻译和句型各一行就够。
- **只根据上下文和公认的常识讲。** 拿不准的写「上下文不够」。读者会把讲解当真，编出来的论文细节比不讲更糟。
- **大白话，最多打一个比方。** 比方是为了让人一下抓住机制，多了反而要读者自己去对应。
- **术语第一次出现写成「中文（English）」。** 读者要能对回原文。
- **字数上限是硬的。** 讲解显示在阅读页侧边的小卡片里，长了要滚动；每多一百字，也是每次学习都多花的 token。
- **不复述原句，不客套，不加总结，不用 Markdown。** 程序按行首的标签拆开显示。

## 在对话里用

用户直接贴一句话或一个词时，按上面的格式回答。没给上下文就只凭这句话讲，并在「前因」里说明是推测。用户追问再展开，展开时不受字数限制。

## 给接这个 skill 的程序：怎么省 token

实测（2026-11-25，Claude Code 2.1.76，同一句话）：

| 调用方式 | 进 | 出 | 用时 |
|---|---|---|---|
| 旧写法：默认系统提示词，提示词和内容一起走标准输入 | 约 7300 | 约 1150 | 22 秒 |
| 下面的写法，句 | 约 700 | 约 330 | 9 秒 |
| 下面的写法，词 | 约 530 | 约 150 | 5 秒 |

1. **换掉默认的系统提示词。** 命令行默认会带上几千 token 的系统提示词、工具说明和记忆文件，讲一句话用不上。系统提示词只放 `prompts/` 里对应的那一份，四行输入走标准输入：

   ```
   claude -p --model sonnet --effort low --system-prompt <提示词全文> --tools "" --strict-mcp-config --mcp-config {"mcpServers":{}} --setting-sources "" --disable-slash-commands --no-session-persistence --output-format json
   ```

   工作目录设成临时目录，免得读到项目里的说明文件。
2. **词和句都用标准模型加低思考量。** 轻量模型在这里不省：它想得多，出的 token 反而更多，还把方向讲反过一次。
3. **学过的存下来，再点直接读存档。** 同一篇、同一段文字、同一版提示词不再调模型；只有读者点「再讲一次」才重新调。
4. **上下文截到约 900 个字符。** 选中超过 500 个字符就不讲，请读者选短一点，一次讲一个点。
5. **不为格式重试。** 输出按行首标签拆；缺一行或多一行就照原样显示。只有输出为空或命令失败才重试一次。

## 换引擎

提示词和四行输入与引擎无关。默认用本机已登录的 Claude 命令行；换成 Codex 等别的引擎时，同样只发这份提示词和四行输入，关掉工具，用最低一档的思考量。

## 例子

句（输入是自编的示例，不是哪篇论文的原文）：

```
论文：A Lease-Based Scheduler for Batch Jobs
小节：3.2 Failure Handling
上下文：Workers may crash or become unreachable at any time. The coordinator assigns each task a lease, which expires unless the worker renews it with a heartbeat. Expired tasks are returned to the queue.
选中：The coordinator assigns each task a lease, which expires unless the worker renews it with a heartbeat.
```

```
大意：协调者给每个任务发一个有期限的「租约」，工人不续就作废。
前因：工人随时可能挂掉或失联，协调者没法直接知道它还在不在干活。
理解：租约（lease）像限时停车票：工人定期发心跳（heartbeat）续费，票就一直有效；不续，到点自动失效，不需要谁来宣布它死了。
后果：过期的任务回到队列，交给别的工人重做，系统不会卡在死掉的工人上。
关键：lease（租约）：带期限的占用权；heartbeat（心跳）：定期报平安；expire（过期）：到点自动失效。
翻译：协调者给每个任务分配一个租约，工人若不用心跳续约，租约就会过期。
句型：A expires unless B renews it：用 unless 说「不做就失效」。
```

词（同一段上下文，选中 `lease`）：

```
是什么：一种带期限的占用权，到期不续就自动收回。
为什么：不用确认对方死没死，靠超时就能安全收回任务。
在这里：协调者发给工人的任务占用期，靠心跳续。
翻译：租约 /liːs/
搭配：renew a lease（续租约）；the lease expires（租约到期）。
```
