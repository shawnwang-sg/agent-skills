# 润色排版规则（给逐条处理的子任务看）

输入是一批抖音收藏的语音转写稿（faster-whisper small，错字多、几乎只有逗号）或图文的识别文字（`【正文】`、`【图1】`…）。
每条输出一个 JSON 对象，整批写成一个 JSON 数组。

## 第一步：判定 verdict

| verdict | 什么时候 | 要填的字段 |
|---|---|---|
| `keep` | 内容和所在收藏分类的主题相符，文字本身能读 | 全部字段 |
| `move` | 放错了收藏分类。例：「厉害」（人生信条、认知、处世、成长）里出现菜谱、健身动作教学、时事阴谋论、搞笑段子 | `move_to`（建议的收藏分类：厉害 / 厉害文字 / 爱好 / 美食 / 身体健康 / 其他）、`reason`、`theme` |
| `low_info` | 文字几乎没有信息量 | `low_info_type`、`reason`、`theme` |

`low_info_type` 只用这几种：
- `画面为主` —— 主要靠图像/演示，文字只有零星几句或只剩标签
- `断续口播` —— 说的话断断续续，要配合动作/画面才能懂（如「这样、再这样、看到没」）
- `纯音乐歌词` —— 背景歌词、BGM、念白，不是讲内容
- `残缺` —— 只有开头一两句就断了，或转写乱到无法还原意思
- `其他`

拿不准是 keep 还是 low_info 时选 keep。
**图文金句不算放错**：「厉害」里的图文（kind=图文）只要是人生信条类的金句，就 keep，不要 move 到「厉害文字」。只有主题不符（菜谱、健身动作等）才 move。只有讲的内容本身有价值才算 keep。

收藏分类的主题：厉害 = 人生信条、认知、处世、成长；厉害文字 = 金句图文；爱好 = 兴趣技能；美食 = 做菜吃喝；身体健康 = 健康养生运动康复。

## 第二步：清洗（只对 keep）

**原则：保留原话，改动不超过约 10%。**只允许做下面这些事：
1. **改转写错字**：同音、近音字按上下文改对，人名、书名、古文、术语尤其要对（梅兰黄→梅兰芳，国感→果敢，绕形→绕行）。改不出来、只能猜的，在猜的词后面加 `[?]`，不要硬编。
2. **删口水词**：啊、呢、嘛、哎呀、对吧、你知道吗、就是说、那个那个、重复的半句，以及片尾/片头引导语（点赞关注、课上见、我们下期见、帮忙点个推荐、评论区告诉我）。
3. **补标点**：断句，补句号、问号、感叹号、冒号、分号、引号。
4. 图文：合并【正文】和各图文字，去掉 `#话题标签`、重复识别出来的同一段字、页码水印。

**不允许**：改写句式、换说法、补充原文没有的意思、总结压缩、调换段落顺序。数字、例子、故事细节一律保留。

## 第三步：排版（markup）

body 用下面这几种标记，其余一律是普通文字：
- 空行 = 分段。一段 3～5 句，按意思断开，不要一大坨，也不要一句一段。
- `## 小标题` —— 只在原文本身有结构时用（「第一……第二……」「五道心法」「先说绕行……再说硬刚」），或全文超过约 800 字需要分节。标题尽量用原文里的词。
- `1. ` 编号列表 —— 原文是并列的几条（第一第二第三、六个「第一性原理」）。原文里的「第一」「第二」可以变成编号。
- `- ` 无序列表 —— 并列举例（A 是…B 是…C 是…）。
- `> ` 引用 —— 原话引用名人语录、书里的句子、别人说的话；对话体（师徒问答、两人对话）每句一行 `> 弟子：……`、`> 师父：……`，说话人标签可以加。
- `**加粗**` —— 每篇 1～3 处，只加在最关键的结论句上。
- 视频在半句话处结束的，最后加 `（原视频到此结束）`。

## 字段

```json
{
  "id": 14,
  "verdict": "keep",
  "theme": "圈子：你只认识这些人",
  "category": "五、人性 · 人际",
  "topic": "圈子",
  "gold": "圈子不是混进去的，而是你变得有价值，变得值得被认识以后，它自己出现的。",
  "body": "……markup 正文……",
  "unsure": 1,
  "note": "可选：改动较大、需要用户确认的地方"
}
```

- `theme`：标题，8～18 字，尽量用原话里的核心说法，可加「：副题」。
- `gold`：从清洗后的正文里**原样**摘一句最值得记住的话（20～60 字）。
- `category`：厉害、厉害文字用这 10 个大类之一（原样写，含空格和点）：
  一、行动 · 自律 · 成长｜二、心态 · 逆境 · 情绪｜三、认知 · 思维｜四、学习 · 读书｜五、人性 · 人际｜六、修身 · 处世｜七、社会 · 职场 · 权力｜八、财富 · 商业 · 投资｜九、身体 · 生活方式｜十、历史 · 家庭 · 情感 · 其他
  其他收藏分类：用该分类 `categories.json` 里已有的大类；没有合适的才新建，并在 note 里说明。
- `topic`：小主题，2～6 字（如：拖延、圈子、自信、领导力、育儿、读书方法），同类意思的用同一个词。
- `unsure`：正文里 `[?]` 的个数。
