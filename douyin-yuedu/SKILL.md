# 抖音收藏转写稿 → 阅读版（yuedu.html）

用户把抖音收藏按收藏夹分类下载在 `D:\douyin\<分类>\`（厉害 = 人生信条、爱好、厉害文字、身体健康、美食），用本地的 douyin-fav-study（`C:\Users\Shugu\douyin-fav-study`，网站 http://127.0.0.1:8765）「只转文字」，转好的条目停在「待提炼」。这个 skill 把这些文字做成一本能读的阅读版。

## 用户定下的要求
- **保留原话**：只改转写错字、删口水词和片尾引导语、补标点。改动不超过约 10%；超过的基本是错字多（whisper small 转中文同音错字多），照改，在质检页列出来。听不清只能猜的标 `[?]`。
- **好读的排版**：用户确认过的格式见 `references/format.md`（分段、`##` 小标题、编号、对话体逐行、引用框、每篇 1～3 处加粗、开头一句原文金句）。
- **一个 HTML**：`D:\douyin\yuedu.html`。顶部 tab = 抖音收藏分类；tab 内按大类 → 小主题分组（「厉害」「厉害文字」用嘉言钞那 10 个大类）；带目录和搜索；每篇显示标题、作者、原视频链接、金句，点开读全文。
- **单独列出**：放错收藏分类的（如「厉害」里的菜谱、健身动作、时事段子），文字没信息量的（画面为主、没文字、断断续续配合动作的口播、纯音乐歌词、残缺）。学习台里因「几乎没有说话内容」跳过的，也自动算进「画面为主」。
- **增量**：之后每新转好约 100 条就整理一次，只处理新的，已整理的不重做。
- **省额度**：用户设过「本周额度超过 70% 就停」。逐条润色要花额度，每批前后用 `get_usage` 看一下。

## 步骤
工作目录 `D:\douyin\_yuedu\`：`todo/` 待处理批次，`done/` 每批结果（JSON 数组，规则见 format.md 的字段说明）。

1. **导出新条目**：
   ```bash
   cd C:\Users\Shugu\douyin-fav-study
   .venv/Scripts/python -X utf8 ~/.claude/skills/douyin-yuedu/scripts/export_batches.py --folders 厉害,爱好 --size 30
   ```
   已在 `done/` 里的 id 自动跳过。
2. **分批润色排版**：每批交给一个子任务（Agent，sonnet 足够），prompt 要点：先读 `references/format.md`，再看 `done/batch_000_trial.json` 里 2～3 条 keep 当样例，处理 `todo/<批>.json`，结果写到 `done/<同名>.json`，写完自己读回校验（条数一致、keep 字段齐全、gold 能在正文里原样找到）。几批可以并行，一个子任务处理 2～3 批。
   - 新的收藏分类第一次处理时，先让一个子任务定下该分类的大类表，存到 `D:\douyin\_yuedu\categories.json`（`{"爱好": ["运动健身", ...]}`），之后的批次都用这张表，保证分类一致。
3. **抽查**：随机看几条 keep 的 body 和原转写对比，重点看有没有改写原话、错字是否改对；move/low_info 是否合理。
   - 子任务偶尔会把「厉害」里的图文金句判成「移到厉害文字」，这是错的（规则里已写明），发现了就改成 keep，补写到 `done/batch_fix_XXX.json`（文件名排在后面的覆盖前面的同 id 结果）。
   - **小主题合并**：并行的子任务起的小主题会很碎（同义词、只有 1 篇的）。看一下各大类的小主题分布，把细碎的写进 `D:\douyin\_yuedu\topics.json`（`{大类: {原小主题: 合并后}}`），每个大类留 2～7 个主题。生成页面时自动套用。
4. **生成阅读页**：
   ```bash
   .venv/Scripts/python -X utf8 ~/.claude/skills/douyin-yuedu/scripts/build_yuedu.py
   ```
   输出篇数、没信息量、疑似分错、视频改动中位数、超 10% 篇数（图文是识别图片文字后重排，不算改动比例；比对时去掉所有标点符号）。第一轮 401 篇视频的改动中位数约 14%，多出来的基本是改错字。可以用无界面 Chrome 截图检查：`chrome --headless=new --screenshot=x.png --window-size=820,1800 file:///D:/douyin/yuedu.html`。
5. **等下一轮**：后台跑 `scripts/wait_new.py --n 100`，攒够 100 条新转好的（或转写队列跑完）就退出，再从第 1 步做一轮。
6. **汇报**：本次新增几篇、各分类篇数、没信息量/疑似分错各几条、平均改动和超 10% 的篇数、本周额度。

## 注意
- 不改、不移动 `D:\douyin` 里的原视频；疑似分错的只列出来，由用户自己在抖音里改收藏夹。
- 不碰学习台的数据库（只读）。
- 超过 15 分钟的长视频在 `D:\douyin\超15分钟长视频\` 里，不转写，也不进阅读版。
