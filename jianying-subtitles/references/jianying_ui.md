# 剪映专业版 UI 坐标参考（2026-11 实测）

环境：剪映窗口全屏，在显示器「TL160MDMP03-0」上，截图坐标系 1389x868。
**换了机器、显示器、分辨率或剪映版本，坐标就会变**。第一轮务必逐步截图确认，再写批量操作。

| 动作 | 坐标 |
|---|---|
| 剪映空白处（取焦点） | (780, 300) |
| 右上「导出」 | (1267, 16) |
| 导出弹窗：标题框（三击后 Ctrl+A 再输入） | (887, 177) |
| 导出弹窗：导出按钮 | (862, 712) |
| 导出完成弹窗：关闭 | (936, 588) |
| 时间轴空白处（之后 Ctrl+A） | (700, 690) |
| 时间轴工具栏：删除 | (284, 614) |
| 顶部「素材」标签 | (29, 50) |
| 素材缩略图（右键 / 拖拽起点） | (287, 158) |
| 右键菜单「删除」 | (317, 280) |

识别时画面中央显示「字幕识别中… N%」。识别完成后时间轴上出现两排字幕。

导出设置只需第一次设好，之后会记住：只勾字幕导出（格式 SRT），关闭视频导出、音频导出和云备份，导出位置设为桌面。

## 一轮的 computer_batch 顺序（可直接套用）

1. 点 (780,300)，点导出 (1267,16)，等 3 秒
2. 三击 (887,177)，Ctrl+A，输入 `jy_<id>`；缩放核对标题后点 (862,712)，等 5 秒，点 (936,588)
3. 点 (700,690)，Ctrl+A，点 (284,614)
4. 点 (29,50)，右键 (287,158)，点 (317,280)，等 2 秒
5. 点 (290,132)，等 3 秒（缩放确认对话框已打开），点 (450,635)，输入 mp3 文件名，回车，等 3 秒
6. 从 (287,158) 拖到 (200,730)，等 2 秒；点 (295,50)，点 (288,239)，点 (148,298)
7. 截图确认：时间轴上有新音频，翻译语言是「中文」。再点 (437,576) 开始识别
