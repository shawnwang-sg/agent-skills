# 剪映批量识别字幕 → 整句双语 SRT

通过电脑控制（computer-use）操作剪映专业版。剪映的语音识别时间戳很准，比 YouTube 自动字幕好得多。

## 产物

对每个 `<base>.mp3`（同一文件夹）：
- `剪映原始字幕/<base>.jy.srt`：剪映原始导出，前 N 块是英文，后 N 块是同时间戳的中文机翻
- `剪映原始字幕/<id>.job.json`：分句和翻译数据 `{"groups": [[1,3],...], "zh": [...]}`
- `<base>.srt`：整句双语，英文在上、中文在下，**GBK + CRLF**（Aboboo 用）
- `<base>.en.srt`：整句纯英文，UTF-8 BOM

`<id>` 是文件名开头的 `课号-段号`，例如 `22-03`。编号对照表 `剪映原始字幕/课件编号对照.csv` 用 `aboboo-courseware/scripts/make_mapping.py` 生成。本 skill 用它来做 id ↔ base 的映射。

## 开工前

1. 旧字幕先挪进 `废弃字幕\`，原始 `.en.srt` 再备份一份。不删任何东西。
2. 先生成编号对照 CSV（见 aboboo-courseware）。
3. 请求 computer-use 权限：`剪映专业版`（Aboboo 和文件资源管理器按需）。用户要先打开剪映，并新建一个空草稿。
4. **先做 1 个给用户看**，确认字幕质量和合并风格以后再批量。

## 剪映一轮（每个片段）

坐标和细节见 [references/jianying_ui.md](references/jianying_ui.md)。每一轮依次是：

1. **导出上一段**：点「导出」。标题填 `jy_<id>`；只勾字幕导出（SRT），视频导出、音频导出、云备份都关掉。导出位置是桌面，点导出后关闭弹窗。
2. **清空**：时间轴 Ctrl+A，再点工具栏删除。素材面板里右键旧素材 →「删除」。
3. **导入下一段**：点「导入」，文件名框输入 mp3 文件名后回车（对话框会停在素材文件夹），再把素材拖到时间轴。
4. **识别**：点「字幕」→「智能字幕/识别字幕」，源语言选英文，「翻译语言」勾上并选**中文**（每轮都要确认，偶尔会跳回「无」），点「开始识别」。
5. 识别一个 6 分钟片段约 1～2 分钟。**不要干等**：先去做翻译归档或 Aboboo 上传，回来再导出。

每一轮之后运行：
```
python -I "<skill>/scripts/archive_exports.py" "<mp3文件夹>"
```
它把桌面上的 `jy_<id>.srt` 改名归档，并列出「待翻译」的 id。

## 分句和翻译（子代理并行）

每攒够 2～3 个待翻译 id，就开一个后台 general-purpose 子代理。提示词模板见 [references/translate_prompt.md](references/translate_prompt.md)，要点如下：
- 英文块 = 不含汉字的块，编号 1..N。按 10～25 词合成整句，分组必须连续、不漏、不重。
- **英文一个字都不改**，听错的词只在中文里按正确意思翻译。
- **硬规则：每句中文必须以汉字（U+4E00–U+9FFF）开头。** Aboboo 在第一个汉字处切分中英文，句首是引号、省略号、数字或英文的话，会被粘进英文行。
- 子代理写好 `<id>.job.json` 后运行 `scripts/jy_merge.py`。脚本会校验分组覆盖和汉字开头，不合格直接报错。
- 汇报每段的块数、句数和明显的听写错误，最后由主代理转告用户。

```
python -I "<skill>/scripts/jy_merge.py" "<jy.srt>" "<job.json>" "<mp3文件夹>" "<base>"
```

## 坑

- **Aboboo 中文乱码**：Aboboo 会忽略 BOM，按内容猜编码，所以双语版必须存成 GBK。GBK 里没有的字符（带音标的字母等）会被去掉音标。
- 剪映偶尔把一句英文直接识别成中文。那一块会被当成中文跳过，英文行少一句，时间轴不受影响。要告诉用户是哪一段。
- 「同时清空已有字幕」的勾选会自己掉，所以每轮都用 Ctrl+A 加删除来清空时间轴。
- 导入对话框偶尔开得慢，导致文件名输进别处。批量操作里要在导入前加等待，导入后截图确认时间轴上确实有音频。
- 同名文件再次导出会弹「文件已存在，覆盖？」。
- 微信、ShellHost 等窗口可能抢焦点，每轮先点一下剪映的空白处。
- 双屏时用 `switch_display` 切屏，切完先单独截一张图，再做批量操作（坐标以截图为准）。
