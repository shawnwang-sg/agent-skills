# 分类规范（classify）

- **动态类目**，不预设固定表；按主题给 **2–6 字中文** 类目。
- **复用优先**：先看 vault 已有 `category`，能归入就别新建近义类。
- **一篇一类**，粒度适中。例：科研方法 / 向量化引擎 / 大模型 / 数据库 / 检索增强 / 多模态。
- 每加一篇新论文都要分类；写进 `meta.category`，build 后 L1 自动分组 + 生成筛选 chip。

## 怎么定 category

1. 列出 vault 现有类目（看各 `papers/*/paper.json` 的 `meta.category`）。
2. 新论文若属于某现有类的同一主题 → 直接复用该类名。
3. 否则起一个 2–6 字的新类名，保持与现有类目同一粒度。
