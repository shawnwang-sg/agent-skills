# 三模式内容规范（modes）

三模式都「英文原文 + 中文翻译」，差别**主要是保留多少原文**，逐级加深。
比例按 **en 词数 ÷ 全文词数** 估算。en 字段放论文**原文句段**（可少量删节合并，别改写成摘要）；zh 给准确翻译。

## 比例约束（半硬约束 + 自检重跑）

- **目标**：skim ≈ 1/5、grasp ≈ 1/3、master ≈ 1/2。
- **容差**：允许 **±20%**（相对目标）。即落在下列区间即算达标：
  - skim：0.16 – 0.24
  - grasp：0.27 – 0.40
  - master：0.40 – 0.60
- **计量**：在 `paper.json` 的 `meta.source_words` 写入**全文英文词数**；`build.py` 会按上表自检，
  每个模式打印 `OK / LOW / HIGH`，并在有超界时给出 `⚠` 提示。`build.py --strict` 会在超界时返回退出码 1。
- **重跑策略**：加工一篇论文时，写完 `paper.json` → build 自检 → 若某模式 `LOW/HIGH`，
  **只修订该模式**（LOW 就补更多原文 `p` 块、HIGH 就精简）→ 重新 build。**最多重跑 2 次**；
  2 次后仍轻微超界则记录现状、不再强行拼凑（保证质量优先于卡线）。

| 模式 | key | 原文比例目标 | 结构 |
|---|---|---|---|
| 鸟瞰 | `skim` | 约全文 **1/5** | framing（一句话结论 / 大问题·具体问题 / 5C terms）+「关键原文摘录」section（摘要 + 引言 + 方法关键句 + 主要结论的原句）+ 值不值深读 |
| 理解 | `grasp` | 约全文 **1/3** | 按论文真实章节多个 section，逐节 `p`(en=原文段落, zh=翻译) + `h3` + `list` 铺主线；重要图用 `figure` + 解读；术语加 `terms` |
| 吃透 | `master` | 约全文 **1/2** | **顺序固定三段**：① 「关键原文精读」（承担 ≥1/2 原文，多 `p` 块按章节铺原文 + 翻译，`h3` 分节）→ ② 「问答」（**≥10 个 `qa` 块**：复现 / 质疑假设 / 局限未来 / 关键设计为什么 / 对新手如何读 / 何时该停…）→ ③ 「全文结构」（`p` + `list` 列骨架） |

## 5C terms（鸟瞰用）

用 `terms` 块给 5 个维度的术语/要点卡：
- **Category** 类别　**Context** 背景　**Correctness** 假设是否成立
- **Contributions** 主要贡献　**Clarity** 是否写得好

每个 term：`w`（英文词）/ `zh`（中文词）/ `m_en`（一句英文白话）/ `m`（一句中文白话）。**`m_en` 与 `m` 须成对**，使术语卡在原文/中文模式下都各自完整对照。
