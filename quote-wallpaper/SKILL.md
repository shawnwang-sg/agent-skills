# 名言文字壁纸

用户想每天在桌面上看到这些话，所以壁纸要**统一、安静、好读**：同一个背景、同一个位置的磨砂框，只换文字。这些规则是用户在样张阶段一步步定下来的，不要自行换风格。

依赖：Python（Pillow）、Chrome 或 Edge。命令都加 `PYTHONIOENCODING=utf-8`。

## 用户定稿的规则（以及为什么）

- **背景**：`雷尼尔雪山_16x10_3072x1920.jpg`（用户选的雪山照片，裁成笔记本 16:10，3072×1920）。脚本先找 skill 的 `assets/`，再找 `~/Pictures/Wallpapers/`；图片不在 git 仓库里，换电脑时要自己放一份到 `assets/`。用户还有一块 16:9 的主屏 2560×1440；需要主屏版本时，背景用 `C:\Users\Shugu\Pictures\Wallpapers\雷尼尔雪山_16x9_2560x1440.jpg`，并把脚本里的 W/H 改成 2560/1440（框按比例缩放）。
- **框永远固定在右上角**：用户原话「保持在右上，有一个磨砂玻璃的固定框，注意位置永远固定」。两种框：
  - ≤100 字 → 顶部横条磨砂框（x 1800～3008，y 64～430），左端停在山顶右侧，不压雪山；
  - 101～300 字 → 右上大磨砂框（x 2060～3008，y 64～880）；
  - >300 字 → 不做（框装不下，字会太小）。
- **字号自动取放得下的最大值**：短句会很醒目，300 字左右约 33～34px（200% 缩放下相当于 17 号字）。
- **换行**：「要有最基础的换行，但是不要太多」——用 `zh_lines.lines_of`：句号/问号/叹号/分号处断开，太短的并到前句；短文最多 4 段、长文最多 6 段；引号没闭合时不断开。
- **风格**：用户否决过楷体、竖排、无框天空字等风格，最终只要磨砂玻璃框 + 宋体深色字。

## 步骤

1. **准备输入**：pages.json（来自 quote-collection-publish，会带类别）、JSON 列表，或空行分隔的 txt。
2. **先出 2 张样张给用户看**（一短一长），尤其是第一次做、换了背景或换了屏幕比例时：
   ```bash
   PYTHONIOENCODING=utf-8 python ~/.claude/skills/quote-wallpaper/scripts/make_wallpapers.py <输入> --out <桌面>/文字壁纸_样张 --limit 2
   ```
   用 Read 打开图片自己先看：字有没有溢出框、有没有一个字单独成行、框有没有压到主体。
3. **批量生成**（几百张要 10～20 分钟，放后台）：
   ```bash
   PYTHONIOENCODING=utf-8 python ~/.claude/skills/quote-wallpaper/scripts/make_wallpapers.py <输入> --out "<桌面>/<集锦名>/壁纸"
   ```
   已存在的图片会跳过（断点续跑）；文字改了要重做加 `--force`。
4. **核对**：数量 = ≤300 字的条数；随机抽 4 张拼成一张小图用 Read 看一眼（PIL 缩到 768×480 拼 2×2）。
5. **汇报**：张数、跳过了多少条超过 300 字的、放在哪、抽查结果。告诉用户设置方法：选中图片右键「设置为桌面背景」，或「设置 → 个性化 → 背景 → 幻灯片放映」选这个文件夹就能轮播。

## 注意
- 桌面路径用系统登记的位置（可能被 OneDrive 重定向），不要硬写 `~/Desktop`；PowerShell 里用 `[Environment]::GetFolderPath('Desktop')`。
- 输出放进桌面文件夹后，OneDrive「图片」同步可能把它挪走；汇报前再确认一次文件还在原处。
