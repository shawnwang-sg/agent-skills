# Aboboo 课件批量制作与上传

通过电脑控制操作 Aboboo（Windows 桌面版）。一个 mp3 对应一个课件，上传后进入小组审核，审核通过后右下角会弹出通知。

## 用户默认设置（2026-11 确认）

| 项 | 值 |
|---|---|
| 课件名称 | `{编号:03d} {视频标题}-part{段号}`，如 `105 Jim Rohn - The Major KEY to Your Better Future is YOU - Full Seminar (Greek Subtitles)-part03` |
| 课件作者 | Shawn |
| 一级分类 | Shawn日常英语 |
| 二级分类 | 磨耳朵 |
| 课程编号 | 和课件编号相同（如 105） |
| 上传方式 | 选项 2「我要让更多人分享本课件」，小组选 **国外日常视频** |
| 编号接续 | 2026-11 已用到 **123**，下一批从 124 开始。开工前和用户确认起始号 |

编号对照表的生成方法（按文件名排序，依次编号）：
```
python -I "<skill>/scripts/make_mapping.py" "<mp3文件夹>" --start 124
```
默认写到 `<mp3文件夹>/剪映原始字幕/课件编号对照.csv`，列为 id、num、name、base。

## 新建一个课件的流程

坐标见 [references/aboboo_ui.md](references/aboboo_ui.md)。

1. Aboboo 主界面 → 工具 →「课件编辑器」，双击标题栏最大化。
2. 选「打开 MP3/WAV 文件制作课件」，在文件名框输入 mp3 的**完整路径**，回车。
3. **导入字幕一定要走菜单**：「导入字幕」→「从文件(lrc,srt,txt)中打开」，输入 `<base>.srt` 的完整路径，回车，再确认覆盖。Aboboo 会按 mp3 缓存旧字幕，不走菜单就会用到旧内容。
4. 缩放检查底部译文栏：中文正常显示、没有乱码，才继续。
5. 关掉右下角弹窗（它会挡住「下一步」），按 Ctrl+N 进入下一步，**截图确认**弹出了「使用默认模板渲染全文？」，选「是」。
   - 如果没弹（遇到过一次），全文编辑区是空的。这时先清空误输入的内容，点工具栏「本地渲染」，再接着下一步。不确认就直接往下走，后面输入的文字会打进正文里。
6. 渲染窗口点「保存到课件编辑器」，关弹窗，点「下一步」进入属性页。
7. 依次填写课件名称、作者、一级分类、二级分类、课程编号：每个框都先点击，再 Ctrl+A，再输入。缩放核对后点「生成课件」。
8. 点「保存」生成 `<base>.q99`。如果提示已存在，选覆盖。
9. 进入上传页，点选项 2，确认小组是「国外日常视频」，然后上传。上传期间会出现进度小窗，一般 10～40 秒。

建议每个课件分两个 computer_batch：第 1～5 步打开、导入、Ctrl+N 后截图；确认渲染提示出现后，第 6～9 步一口气做完。

## 更新已上传的课件

- 重新上传同名课件必须**版本号更大**，否则报「版本号的值[1]不大于已存在的课件[1]」。做法：课件编辑器选「编辑Q99课件文件」，打开原 `.q99`，版本号会自动 +1。然后重新导入字幕，用「本地渲染」重渲全文（不重渲会被审核驳回，理由是「音频绑定有缺陷」），保存时确认覆盖，再上传。
- 用户以前手工上传过的课件，先备份旧 q99（`废弃字幕\旧_<base>.q99`），再走上面的更新流程。

## 坑

- **上传报「临时文件…q99 不存在」**：先别重传，等一会儿看右下角有没有这个课件的审核通过通知。2026-11 那次报错（120）其实已经传上去了。确实没上去的话，用「编辑Q99课件文件」打开已保存的 q99 重新上传。
- 审核通过的弹窗会盖住右下角的「下一步」。每次点右下角按钮之前，先点一下弹窗位置把它关掉。
- 双语 SRT 必须是 GBK 编码，而且每句中文都要以汉字开头。jianying-subtitles 的 jy_merge.py 已经保证了这两点。
- 任务管理器、UAC 这类高权限窗口控制不了，需要请用户处理。
- 上传比较慢时可以先去剪映那边干活，回来再截图检查。
