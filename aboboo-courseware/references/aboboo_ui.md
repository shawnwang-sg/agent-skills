## computer_batch 拆法

- **批次 A**：关弹窗 → 取焦点 → 打开课件编辑器 → 最大化 → 选项 1 → 输入 mp3 路径并回车（等 5 秒）→ 打开导入字幕菜单 → 选「从文件中打开」→ 输入 srt 路径并回车 → 确认覆盖 → 缩放检查译文栏 → 关弹窗 → Ctrl+N → 等 4 秒 → 截图。
- **批次 B**（截图里看到渲染提示之后）：选「是」→ 保存到课件编辑器 → 关弹窗 → 下一步 → 填 5 个字段 → 缩放核对 → 生成课件 → 保存 → 上传 → 等 10 秒 → 截图。

输入路径用 `type`（会走剪贴板），中文路径没问题。
