# 本地视频收藏 → 阅读页（yuedu.html）

一个「库」= 一个根目录：下面是分类子文件夹（如抖音收藏夹分类 `D:\douyin\厉害\`），或视频直接平铺在根目录（如 `D:\xiaohongshu\`）。视频文件名是「作者 - 标题.mp4」，图文是「作者 - 标题」文件夹（图片 + 正文.txt）。阅读页生成在根目录 `yuedu.html`，用相对路径播放本地视频，所以不能单独挪走。

已有的库：
- `D:\douyin`（抖音收藏，5 个 tab：厉害、爱好、厉害文字、身体健康、美食），配置和规则在 `D:\douyin\_yuedu\`。
- `D:\xiaohongshu`（小红书收藏，约 1100 个视频 + 40 多条图文，平铺）：还没建库。

## 用户定下的要求（所有库通用）
- **保留原话**：只改转写错字、删口水词和片头片尾引导语、补标点断句；视频改动 8%～15%，不超过 15%（2026-11-07 从 10% 放宽到 15%）。只能猜的标 `[?]`。
- **好读的排版**：分段、`##` 小标题、编号、对话逐行、引用框、每篇 1～3 处加粗、开头一句原文金句。完整规则在 `references/format.md`。
- **一个 HTML**：tab = 分类，tab 里按大类 → 小主题；左侧固定导航、文章默认展开、页面占满宽度；搜索；每篇「原视频」在页内弹窗播本地文件。
- **左侧导航三级**：大类 → 小主题 → 每篇标题（点了直接跳到那篇），侧栏 340px 宽。
- **删除 / 回收站**：每篇阅读稿和待处理清单的每一行后面都有「删除」，删了进「回收站」tab，可恢复，不删文件。记录存在浏览器 localStorage（按页面路径分开）；回收站「导出清单」存成 `<页面>-回收站.json`，用户交来时放到 `<库>/_yuedu/deleted.json`（`{"ids": [...]}`），重新生成时预先放进回收站；以后整理也可以参考它跳过用户删掉的。
- **本地刷**：每个 tab、大类、小主题都有「▶ 连播」「🔀 洗牌」；视频播完自动下一条，图文自动往下滚、5～15 秒后下一条；↑/↓、滚轮切换；tab 顶部「连播带图文」勾选（不勾只播视频）。
- **本地灵活整理**：线上收藏夹只是基础云盘。放错分类的，在本地挪到正确文件夹再照常整理；「其他」类（影视剧台词、时事、体育新闻）不挪也不整理，只列在待处理清单。
- **单独列出**：没信息量的（画面为主、断续口播、纯音乐歌词、残缺），学习台因「几乎没有说话内容」跳过的也算进去。内容有价值但转写乱到还原不了的，`low_info_type` 可以写自定义分组（如抖音美食的「转写太乱（待重转）」），待处理清单里单独一组，以后再用大模型重转。
- **超过 15 分钟的长视频不处理**，学习台会跳过、文件留着（抖音库单独放在 `超15分钟长视频\`，config 的 exclude 里）。
- **不重复下载**：只用本地文件。
- **增量**：每新转好约 100 条整理一轮，已整理的不重做。
- **省额度**：用户设过「本周额度超过 70% 就停」，每轮前后看一下 `get_usage`。

## 工具和文件
脚本都在本 skill 的 `scripts/`，一律加 `--root <库根目录>`，用系统 Python `python -X utf8` 跑（只用到 sqlite，读学习台数据库只读）。下面 `S=~/.claude/skills/video-yuedu/scripts`。

| 脚本 | 作用 |
|---|---|
| `init_lib.py` | 建 / 改库配置 `_yuedu/config.json`，按文件夹抽样标题 |
| `import_lib.py` | 把各 tab 文件夹和根目录交给学习台「只转文字」（调 `/api/import_folder`） |
| `wait_new.py` | 后台等，新转好的攒够 N 条（或队列跑完）就退出 |
| `topic_list.py` | 生成 `topic_list_<tab>.txt`（大类 + 已用小主题），派子任务前跑 |
| `export_batches.py` | 导出待润色条目成 `todo/batch_*.json`（`--ids` 指定条目） |
| `strip_fillers.py <done 文件>` | 删标点前残留的语气词（啊/呀/嘛/是吧），不改比例 |
| `relocate.py` | 按润色结果在本地挪文件（move 到本库 tab 的、平铺库 keep 带 tab 的），同步学习台路径；`--export` 导出挪过的重新整理；`--undo` 撤回 |
| `rework_export.py` | 导出改动超 15% 的返工批次 |
| `build_yuedu.py` | 生成阅读页 |
| `lib.py` | 库配置和公共函数 |

库的工作目录 `<根>/_yuedu/`：`config.json`、`rules.md`（这个库特有的规则）、`categories.json`（`{tab: {大类: [建议小主题]}}`，共用一套大类可写 `{"厉害文字": "厉害"}`）、`topic_list_<tab>.txt`、`topics.json`（小主题合并表 `{大类: {原: 合并后}}`）、`corrections.json`（用户指出的错字 `{id: [[原, 改成]]}`）、`todo/`、`done/`（文件名排后面的覆盖前面同 id 的结果）、`moves.json`。

**学习台**：`C:\Users\Shugu\douyin-fav-study`（.claude/launch.json 里的 `douyin-fav-study`，端口 8765）。它有「导入本地文件夹 · 只转文字」、跳过超长视频、本地挪动记录（relocated.json）这些功能，所有库都用它转写（数据库里按路径区分库）。小红书版学习台 `C:\Users\Shugu\xhs-fav-study`（8766）没有本地导入功能，不用它转写。转写是 faster-whisper small、CPU，约 60 条/小时（短视频更快）。

## 新建一个库（第一次）
1. **建配置、看标题**：`python -X utf8 $S/init_lib.py --root D:\xiaohongshu --title "阅读 · 小红书收藏" --link-label 小红书原链接`。有分类文件夹的会自动当 tab；平铺的库看抽样标题，跟用户商量定 5～8 个 tab（`--tabs 职场,AI,美食,...`）。
2. **定大类**：每个 tab 抽 150 个标题定 8～10 个大类（「一、xxx」带序号），写进 `categories.json`；人生信条 / 金句类可直接用抖音库「厉害」那 10 大类。写 `rules.md`：每个 tab 收什么、`move_to` 能填哪些、特殊排版（如菜谱 = 简介 + 食材 + 做法）。参考 `D:\douyin\_yuedu\rules.md`。
3. **转写**：确认学习台开着（没开就用 preview_start 启动 `douyin-fav-study`），`python -X utf8 $S/import_lib.py --root <库>`。学习台按文件写入时间排队；看进度用它的网页或 `wait_new.py`。
4. 之后按「每一轮」做。

## 每一轮（攒够 ~100 条新转写）
1. `python -X utf8 $S/topic_list.py --root <库>`，再 `export_batches.py --root <库> --size 30`。
2. **分批润色**：每 2～3 批交给一个子任务（Agent，sonnet），几个并行。prompt 模板：
   > 把 `<todo 批次路径>` 里的转写稿整理成阅读版，结果写到 `<库>\_yuedu\done\` 同名文件（JSON 数组，UTF-8，ensure_ascii=False）。临时脚本放 `<scratchpad>\<自己的子目录>\`。先完整读 `~/.claude/skills/video-yuedu/references/format.md`、`<库>\_yuedu\rules.md`，category/topic 用 `<库>\_yuedu\topic_list_<folder>.txt`。看 `<一个合格的 done 文件>` 里 2～3 条 keep 当样例。逐条手工处理，写完按 format.md 末尾自检。简短汇报：每批 keep/move/low_info 数、视频改动中位数和最大值（列出 >15% 的和原因）、新起的小主题、拿不准的。
   - 这批是什么内容（运动教学、金句图文、菜谱……）和这个库踩过的坑，在 prompt 里点一句。
3. **验收**（每批都要看，子任务的汇报不等于结果）：
   - 改动中位数 <6% 的批次：抽一篇读，常见是只加了分段、错字和呢/啊都没动、长段逗号串没断 → 打回，点名具体没改的错字。原稿本来就干净的短条除外。
   - 中位数 >15% 或有内容性猜改（改了意思）→ 打回，逐篇手工改回原话，只留改错字。
   - 改得「意思反了」的（如「没有能力」→「有能力」）对照原稿和标题核实，有依据才留。
   - 返工后改动骤降到 2～3% 的：读一读，可能是把乱码原样塞回 + 满篇 [?]，这种改判 low_info，写进 `done/batch_fix_XXX.json`。
   - 子任务用脚本批量撤回 / 批量断句的，读起来会断句错乱、口水词回潮 → 打回。
4. `strip_fillers.py <done 文件>`（每个新 done 文件跑一次）。
5. **小主题**：`topic_list.py` 后看各大类，碎的（1 篇、同义词）合并进 `topics.json`，每个大类留 2～7 个。
6. **本地挪动**：`relocate.py --root <库> --dry-run` 看一眼，再 `relocate.py --root <库> --export`，把导出的 `batch_reclass_*` 交给子任务（「已挪到正确分类，默认 keep，不要再判 move」）。挪动会改学习台路径，学习台的「只下载」同步也不会再复制回原分类。
7. `build_yuedu.py --root <库>`，输出篇数、没信息量、疑似分错、视频改动中位数、超 15% 篇数。
8. 后台 `wait_new.py --root <库> --n 100 --max-hours 24`，等下一轮。
9. **汇报**：新增几篇、各 tab 篇数、没信息量 / 疑似分错、改动中位数和超 15% 篇数、打回了什么、需要用户确认的（猜的人名术语、可疑出处、重复收藏）、本周额度。

超 15% 的集中返工：`rework_export.py --root <库>` 导出，子任务逐篇手工改，结果写 `done/batch_rework_*.json`。

## 用户亲自指出的错字
写进 `corrections.json`（如 `{"211": [["智慧[?]", "志气"], ["事业[?]", "事业"]]}`），生成页面时套用到标题、金句、正文，返工也不会冲掉。改完重新生成，grep 确认。

## 测试阅读页
内置浏览器打不开 file://：在 `.claude/launch.json` 加一个 `python -m http.server <端口> --bind 127.0.0.1 --directory <库根目录>` 的配置，preview_start 打开 `/yuedu.html`。这个服务器不支持拖进度条，测「播完自动下一条」用 `video.dispatchEvent(new Event('ended'))`。用完 preview_stop。

## 注意
- 除了 relocate.py 的挪动，不改、不删库里的原视频；挪动都有 moves.json 记录，可 `--undo`。
- 改动比例 `change_pct`：去掉所有标点和排版标记逐字比，繁体先用 zhconv 转简体（系统 Python 装了 zhconv）；图文不算。菜谱的「## 食材」整节（从后文摘的清单）和「## 做法 / 步骤」这类结构小标题不算改动（2026-11-08 加的：不排除时菜谱中位数虚高到 20%）。
- 学习台的 `app/worker.py` 有本 skill 依赖的改动（本地导入、只转文字、跳过长视频、relocated.json），在学习台仓库里还没提交。
