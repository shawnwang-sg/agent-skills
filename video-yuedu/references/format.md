# 润色排版规则（给逐条处理的子任务看）

输入是一批收藏视频的语音转写稿（faster-whisper，错字多、几乎只有逗号），或图文的识别文字（`【正文】`、`【图1】`…）。
每条有 `folder`（它现在所在的分类 tab）、`kind`（视频 / 图文）、`title`、`author`、`transcript`。
每条输出一个 JSON 对象，整批写成一个 JSON 数组。另外两份要先看：
- `<库>/_yuedu/rules.md`：这个库特有的规则（各 tab 收什么、move_to 能填哪些、特殊排版），和本文冲突时以它为准。
- `<库>/_yuedu/topic_list_<tab>.txt`：这个 tab 的大类和已用过的小主题。

## 第一步：判定 verdict

| verdict | 什么时候 | 要填的字段 |
|---|---|---|
| `keep` | 内容和所在分类的主题相符，文字本身能读 | 全部字段 |
| `move` | 放错了分类（如人生信条分类里出现菜谱、健身动作教学、影视剧台词、时事段子） | `move_to`（rules.md 里列的分类名，或「其他」）、`reason`、`theme` |
| `low_info` | 文字几乎没有信息量 | `low_info_type`、`reason`、`theme` |

`low_info_type` 只用这几种：
- `画面为主` —— 主要靠图像/演示，文字只有零星几句或只剩标签
- `断续口播` —— 说的话断断续续，要配合动作/画面才能懂（如「这样、再这样、看到没」、跟练口令）
- `纯音乐歌词` —— 背景歌词、BGM、念白，不是讲内容
- `残缺` —— 只有开头一两句就断了，或转写乱到无法还原意思
- `其他`

拿不准是 keep 还是 low_info 时选 keep。只有讲的内容本身有价值才算 keep。

**还没分类的条目**（folder 是 config 里的 inbox，默认「未分类」，平铺的库都是这种）：不判 move，按内容判 keep / low_info，keep 的另外填 `tab`（从 rules.md 列的 tab 里选一个最合适的），category / topic 用那个 tab 的 topic_list。之后会按 tab 把文件挪进对应文件夹。

**已经挪过分类的条目**（批次文件名是 `batch_reclass_*`）：folder 就是新分类，默认 keep，不要再判 move。

## 第二步：清洗（只对 keep）

**原则：保留原话，视频改动 8%～15%，不超过 15%。**只允许做下面这些事：
1. **改转写错字**：同音、近音字按上下文改对，人名、书名、古文、术语尤其要对（梅兰黄→梅兰芳，国圣机→腘绳肌）。能按上下文确定的都要改；改不出来、只能猜的，在猜的词后面加 `[?]`，不要硬编。
2. **删口水词**：句中无意义的啊、呢、嘛、哎呀、就是说、那个那个、然后然后、口误重复的半句，以及片尾/片头引导语（点赞关注、课上见、我们下期见、评论区告诉我、卖课推广）。跟观众说话、带语气的原话（「老师们」「好不好」「对吧」）保留。
3. **补标点、断句**：逗号串里完整的句子改成句号，补问号、感叹号、冒号、引号。
4. 图文：合并【正文】和各图文字，去掉 `#话题标签`、重复识别出来的同一段字、页码水印、评论截图里无关的对话；识别错字按上下文改。图文不算改动比例。

**不允许**：改写句式、换说法、调换语序、补充原文没有的意思、总结压缩、调换段落顺序、内容性的猜改（把「侧腹」改成「下腹」）。数字、例子、故事细节一律保留。只改错字也压不到 15% 的，note 写「转写错字多」，不要把改对的字改回去。

**逐条手工改，不准写脚本批量改正文**（试过：程序批量撤回或批量断句会留下断开的逗号、乱码、恢复口水词）。脚本只用来拼装 JSON 和校验。

## 第三步：排版（markup）

body 用下面这几种标记，其余一律是普通文字：
- 空行 = 分段。一段 3～5 句，按意思断开，不要一大坨，也不要一句一段。
- `## 小标题` —— 只在原文本身有结构时用（「第一……第二……」「五道心法」），或全文超过约 800 字需要分节。标题尽量用原文里的词。
- `1. ` 编号列表 —— 原文是并列的几条。原文里的「第一」「第二」可以变成编号。
- `- ` 无序列表 —— 并列举例。
- `> ` 引用 —— 名人语录、书里的句子、别人说的话；对话体每句一行 `> 弟子：……`。
- `**加粗**` —— 每篇 1～3 处，只加在最关键的结论句上。
- 视频在半句话处结束的，最后加 `（原视频到此结束）`。

## 字段

```json
{
  "id": 14,
  "verdict": "keep",
  "theme": "圈子：你只认识这些人",
  "category": "五、人性 · 人际",
  "topic": "圈子",
  "gold": "圈子不是混进去的，而是你变得有价值，变得值得被认识以后，它自己出现的。",
  "body": "……markup 正文……",
  "unsure": 1,
  "note": "可选：改动较大、需要用户确认的地方",
  "tab": "只有还没分类的条目才填"
}
```

- `theme`：标题，8～18 字，尽量用原话里的核心说法，可加「：副题」。
- `gold`：从清洗后的正文里**原样**摘一句最值得记住的话（20～60 字），去掉 `**` 后必须能在 body 里找到。
- `category`：topic_list 里的大类名，原样写（含空格和点）；没有合适的才新建，并在 note 里说明。
- `topic`：小主题，2～6 字，优先用 topic_list 里已有的，同类意思用同一个词。
- `unsure`：正文里 `[?]` 的个数。

用系统 Python（`python -X utf8`）读回自己的输出：条数、id 顺序和输入一致；keep 字段齐全；gold 在正文里；视频 keep 的改动比例：

```python
import sys; sys.path.insert(0, r"C:\Users\Shugu\.claude\skills\video-yuedu\scripts")

change_pct(transcript, body)   # 图文返回 None
```

超过 15% 的逐篇手工改回原话；低于 5% 的检查是不是漏改了错字、口水词、没断句（原稿本来就干净的短条除外）。
